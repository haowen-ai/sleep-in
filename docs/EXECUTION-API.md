# Execution API

All public routes require the existing session/CSRF contract and workflow authorization.

- `POST /api/workflows/{wid}/nodes/{nid}/test` (administrator), body exactly one of `{inputs: {...}}` or `{sample_run_id, sample_node_id?}`. Returns 202 run. Tests only the selected current-draft node using explicit inputs or that workflow's historical recorded inputs; freezes source/runtime, removes all edges and mapping expressions, sets `test=true` and `test_node_id`. No upstream execution or implicit historical injection.
- `GET /api/workflow-runs/{rid}/nodes/{nid}/sample`: `{inputs, run_id, version_id, produced_at, stale}`. Reading a sample does not admit a run.
- Node `config.retry`: `{max_attempts: 1..5, delay_seconds: 0..60, safe_to_retry: boolean}`. More than one attempt requires explicit safe-to-retry declaration. SQL writes additionally require `idempotent:true`. Interrupted/unknown side effects, cancellations and timeouts never auto-retry. Attempts have separate immutable logs/timestamps and directories. n8n drives retry submission.
- Artifact binding: `{source:'artifact', node_id, name}`. Must be reachable successful upstream. Value becomes a checksum-verified read-only copy descriptor `{path,name,mediaType,size,sha256}` in the current attempt's `inputs/` directory. No producer machine paths are passed.
- Oversized data (>1 MiB) is a complete JSON artifact referenced by `output.data_ref`; downstream mapping transparently verifies and loads complete data. `GET /api/workflow-runs/{rid}/nodes/{nid}/output?offset=0&limit=100&path=rows` gives bounded previews, total and pagination; download artifact for complete data.
- `POST /api/workflows/{wid}/triggers/{tid}/run` accepts `{params,idempotency_key}`; enabled API/manual trigger only. Trigger parameter schema and pinned/current publication selection apply. Trigger `overlap` is `skip` (default) or `queue`, `queue_limit` 1..100 (default 10). Runs freeze version at admission. Same trigger/key returns same run.
- Scheduled trigger `missed_policy`: `skip` (default) or `latest_once`; `grace_seconds` 1..86400 (default 7200). Recovery records gap; only newest missed occurrence within grace is admitted, never backlog. Disabled triggers retain configuration and do not drain pending occurrences.

Internal node adapter uses authenticated POST `/internal/workflows/{rid}/nodes/{nid}/submit` (body `{retry:true}` permitted only for declared safe retry) and GET `/internal/workflows/{rid}/nodes/{nid}/status`. Both return small `{node_id,status,terminal,retry_ready,attempt}` envelopes. Submit is idempotent per run/node/attempt. n8n polls with Wait nodes; completion markers only emerge after terminal states. POST `/internal/workflows/{rid}/claim` with `{execution_id}` claims the sole graph entrance lease; duplicate execution IDs cannot dispatch.

Credentials: admin `GET/POST /api/workflow-credentials` and `PUT /api/workflow-credentials/{id}`. Create `{name,value,allowed_workflows:[]}`; update preserves omitted fields and rotates revision on value change. Responses never contain value/encrypted text. Binding `{source:'credential',credential_id}` resolves authorized current revision at execution. Inputs and known-secret logs/data are masked before persistence; historical credential/artifact samples require explicit rebinding. Export removes credential IDs and retains the unbound credential source for review.

Workflow `run_name_template` accepts `{workflow}`, `{date}` (UTC admission date) and scalar `{params.field}` placeholders, up to 500 characters; `run.name` freezes admission rendering. Migration handoff and restored-version rebuild flags block production admission. Maintenance pauses new production admission; existing runs continue.

Portable source projects: template nodes may include `project:{name,language,entrypoint,files:{relativePath:base64},config}`. Export verifies file hashes, removes instance project IDs/directories and includes the complete source payload within the documented template size bound; import validates every path/base64 value before creating a new managed source project. Project config is limited to portable execution fields. Runtime/credential/connection references still require rebinding. User-authored code/literals remain explicitly reviewable export content.

SQL datasets default to a complete 100 MiB cap; administrator-authored node `config.max_output_bytes` may lower it (1..104857600). Schema, portable-value and quota validation occur before committing a write transaction. Values exceeding the 1 MiB inline presentation limit spill to the same complete dataset artifact path as language output.

Concurrency: the compiler submits nodes sharing the same predecessor set before polling any sibling, including multiple roots; the node worker then executes them concurrently. Retry submissions have separate n8n entrances. Different predecessor groups remain subject to n8n scheduling order; no universal maximum-parallelism guarantee is made. The actual n8n acceptance test compares worker start/end timestamps rather than inferring concurrency from graph fan-out.

Recovery: node worker PID, process-group/start identity and cwd are persisted through runtime lifecycle hooks. On coordinator recovery, matching detached workers inside the run directory receive termination; stale/reused/unverified PIDs are never blindly signalled. Interrupted work is marked uncertain/failed and never automatically retried, even when a normal retry policy exists. Recovery records termination evidence separately from business outcome.

Known injected credentials are also masked in downloadable UTF-8 artifacts; descriptors carry `redacted:true` and updated size/checksum. A matching non-UTF8 binary artifact is rejected instead of silently corrupting it. Encoded or otherwise transformed secrets are outside the detection claim.

Connection rotation: administrator/CSRF `PUT /api/connections/{id}` accepts `{name?,config?,write_enabled?,allowed_workflows?}`. Dialect is immutable. Config merges recursively; omitted keys, nulls and blank strings preserve prior values (including passwords and nested TLS credentials). A successful update creates a new revision and resets verification to `untested`; the response exposes no decrypted config. Previously published/admitted runs resolve the current authorized connection revision at node execution and record it, while their graph/runtime snapshot remains immutable. SQLite remains managed storage, never an arbitrary host path.

Portable schema metadata: `metadata.logicalType:"timestamp"` on a string validates a real ISO date/time with seconds and explicit `Z` or `±HH:MM` timezone. Values retain their original text and offset. Decimal and large-integer portable values use string schemas annotated with `metadata.logicalType:"decimal"` or `"integer"`; no implicit numeric conversion is performed. The initial contract supports 100-level nesting and 10,000 object properties when within the existing byte quotas. Python/JavaScript helpers reject native objects with JSON/artifact guidance; Java/C/C++ use explicit JSON file protocols rather than a native-object helper.

Inline threshold measurement is the UTF-8 byte length of the complete structured `data` object serialized by the service (not the worker envelope or a preview). Exactly 1 MiB remains inline; 1 MiB plus one byte becomes a complete checksum-verified JSON dataset artifact. This supersedes the historical ART02 test wording that required an error above 1 MiB, aligning it with PRD A05 and the original complete-data contract. The 100 MiB/100-artifact aggregate quota still applies.
